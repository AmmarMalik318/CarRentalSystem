Project Description

The Car Rental System is a Java-based desktop application developed using Swing GUI. It demonstrates key software engineering concepts such as Event Handling, Exception Handling, Code Refactoring, Unit Testing, and Git version control.

The system allows users to rent and return cars while maintaining proper validation and error handling.

✨ Features
🚘 View available cars
🔑 Rent a car using Car ID
🔄 Return rented cars
🖥️ Interactive GUI using Java Swing
⚠️ Input validation and error messages
🧩 Exception handling for runtime errors
🧪 Unit testing using JUnit
🧼 Clean code with layered architecture (Model, Service, UI)
📂 Git version control with meaningful commits
🛠️ Technologies Used
Java (JDK 17+ recommended)
Java Swing (GUI)
Object-Oriented Programming (OOP)
JUnit 5 (Testing)
IntelliJ IDEA
Git & GitHub
